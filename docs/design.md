# web-admin 设计规范

面向国内运营团队。高效、清晰、专业。

## 调色板

| Token | 色值 | 用途 |
|-------|------|------|
| sidebar | #1E1E2D | 侧边栏底色 |
| sidebar-hover | #2A2A3C | hover |
| primary | #4F6EF7 | 主操作色 |
| surface | #F4F5F7 | 主背景 |

## 字体

系统字体栈（PingFang SC 优先）

## 布局

| 断点 | 侧边栏 |
|------|--------|
| < 1024px | 隐藏，汉堡按钮唤出侧滑覆盖层 |
| ≥ 1024px | 固定 224px |

## 组件

侧边栏：深蓝底 / 当前页高亮 / 底部退出登录
统计卡片：白底 border / 大数字
表格区：白底 border / 筛选 tab
表单触控目标 ≥ 44px
