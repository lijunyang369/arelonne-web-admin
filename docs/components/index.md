# 公共组件

项目共享组件库。每个组件独立文件，位于 `src/components/shared/`。

## 组件清单

| 组件 | 文件 | 用途 |
|------|------|------|
| Table | [`Table.tsx`](./Table.md) | 通用数据表格：标题行、客户端分页、加载态、空状态 |

## 使用公约

1. **导入路径** — 一律从 `@/components/shared/<Component>` 导入
2. **类型导出** — 组件相关的 TS 类型随组件一起导出（如 `Column<T>`）
3. **设计对齐** — 遵循 [web-admin 设计规范](../design.md)
4. **客户端组件** — 需要交互的组件标记 `'use client'`，纯展示组件保持服务端渲染
